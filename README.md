# Google Maps Leads Guide: Grow With Khalaf

An Arabic guide to pulling a B2B lead list from Google Maps with [gosom/google-maps-scraper](https://github.com/gosom/google-maps-scraper) (MIT), installed as a Claude Code skill: setup, the request prompt, cleaning the list, and the outreach messages (WhatsApp, call, email) that turn it into conversations. This repo redistributes none of the tool's code; it only links to it.

Live page: https://mohamedkhalafalla.github.io/gwk-leads-guide/

Names and numbers are illustrative. Not affiliated with the tool's author, Google or Anthropic.
